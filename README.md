# 他人と比較できる支出表

## 概要
毎日の支出を記録し、月別、年間で比較できる支出表です
ユーザーは収入を設定することができ、同じ収入帯の他ユーザーの平均と比較できます
自身が特に節約、投資している項目を設定することができ、同じ項目を設定している同収入帯との比較も行えます

今回はSpringBootの学習として作成しているため、サーバーやデザイン部分は省略し
ローカルで動作することを目的としています。


## 主要技術
+ Springboot       4.1.1
+ Tymeleaf         3.1.5RELEASE
+ H2 DataBase      2.4.240
+ Spring Security  7.1.1
